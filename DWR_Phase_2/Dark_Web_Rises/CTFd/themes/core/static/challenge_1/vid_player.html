Listen Backwards

A good clinician always listens closely to their patients, but some messages are not meant to be understood as they first appear. When the sound is examined beyond what the ears can hear, patterns begin to emerge.

Open the terminal’s frequency visualizer and study the heat map of the audio track. The vertical bars of light conceal a secret command written in Morse Code. The dots and dashes are only the beginning pay close attention to the order in which the message presents itself. Trace the pattern carefully to break the first lock

Flag format: CTF{your_decoded_string}
// reference

International Morse Code

A short mark is a dot; a long mark is a dash. On the visualiser, read a narrow bar as a dot and a wide one as a dash, and treat the gaps between groups as letter boundaries.
